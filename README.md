# کالیمبای نیایش

یک کالیمبای آرام برای نیایش. همه‌چیز روی همین گوشی می‌ماند و هیچ صدایی از سرور نمی‌آید؛ صدا با خودِ مرورگر ساخته می‌شود.

## باز کردن

صفحه را با یک وب‌سرور ساده باز کن (ماژول‌ها با `file://` کار نمی‌کنند):

```
python -m http.server 8931
```

بعد برو به `http://localhost:8931`.

## چه چیزهایی این‌جاست

- نواختن با لمس، چند انگشت، کشیدن روی زبانه‌ها، و کلیدهای کیبورد
- ضبط به‌صورت نت، پخش، تکرار، و ذخیره روی همین دستگاه
- دانلود WAV و فرستادن فایل
- لینک آهنگ داخل آدرس صفحه
- ساخت ویدیو، اگر مرورگر بتواند
- شبکه‌ی نت و نت‌نویسی متنی
- کار آفلاین بعد از یک بار باز شدن

آهنگ‌ها در IndexedDB همین مرورگر هستند. اگر اطلاعات مرورگر پاک شود از بین می‌روند؛ از دکمه‌ی پشتیبان یک فایل JSON بگیر.
